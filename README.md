# Sustainable-Transportation-Planner
A responsive website for sustainable transportation and traffic management
## About the Project
The **Sustainable Transportation Planner** is a responsive web-based application designed to help users understand and choose sustainable transportation options while creating awareness about **traffic congestion and vehicle emissions**.

The project demonstrates how HTML, CSS, and JavaScript can be used to develop an interactive solution for sustainable transportation planning.

## Problem Statement

Traffic congestion leads to increased travel time, fuel consumption, and vehicle emissions. These issues contribute to air pollution, climate change, and reduced quality of life in urban areas.

## Proposed Solution

The Sustainable Transportation Planner provides users with interactive tools to compare transportation options, calculate travel-related information, and explore sustainable transportation choices.
